# 占いWebアプリ3サイト差別化設計書

**日付**: 2026-05-19
**プロジェクト**: luna-moonlight / luna-papermoon / luna-void
**ステータス**: 承認済み

---

## 概要

fortune-app（LUNA ORACLE）の3テーマ派生サイトを、完全に独立した3リポジトリとして分離し、それぞれ異なるペルソナ・プロンプト・UX・ターゲット層・独自機能を持つ独立ブランドに再構築する。

統計学的占術（西洋占星術・数秘術・九星気学・六星占術・四柱推命・タロット）による精度の高い診断という根底は3サイト共通で維持する。

## 現状の問題

- 3サイトとも同じ「Madame Lune」が同じ口調で同じ11セクション構成の鑑定を返している
- 差別化はCSSの色とアニメーションのみ
- 人相占い・手相占いにテーマ対応なし
- Theme Aはdaily.htmlが存在せずデフォルトにフォールバック
- 同一リポジトリのため、デプロイ事故で全サイトが影響を受ける

## アーキテクチャ方針

### 3リポジトリ完全分離

| | luna-moonlight | luna-papermoon | luna-void |
|---|---|---|---|
| ローカル | `/Users/kousuke/luna-moonlight/` | `/Users/kousuke/luna-papermoon/` | `/Users/kousuke/luna-void/` |
| GitHub | 新リポジトリ | 新リポジトリ | 新リポジトリ |
| Render | 既存サービス紐替え | 既存サービス紐替え | 既存サービス紐替え |
| DB | 独立SQLite | 独立SQLite | 独立SQLite |

### 分離時の作業

各リポジトリでfortune-appをフォークした上で:

1. 他テーマのテンプレートディレクトリを削除（例: moonlightならb/, c/を削除）
2. 自テーマのテンプレートをルートテンプレートに昇格（a/ → templates/直下）
3. 他テーマのCSSファイルを削除
4. テーマ切替ロジック（deps.pyのBrowserIdMiddleware、FORCED_THEME）を削除
5. _t()ヘルパーを削除し、テンプレートパスを直接指定に変更
6. プロンプトファイルをサイト固有のものに差し替え

### 元のfortune-app

テーマ切替可能な統合版としてそのまま残す。変更なし。

## サイトA: luna-moonlight（月光の間）

### ブランドコンセプト

神秘的で荘厳な月の神殿。訪れた者は月の光に導かれ、Madame Luneの言葉を受け取る。

### ペルソナ: Madame Lune（マダム・リュンヌ）

- 一人称: 「私」
- 語尾: 「〜よ」「〜ね」「〜わ」
- トーン: 神秘的・優美・距離感のある導き手
- 特徴: 詩的で比喩表現を多用。直接的なアドバイスより暗示で導く
- 語り口: 「月が教えてくれたの」「星の配置がそう告げているわ」「あなたの魂はね、こう囁いているの」
- 禁止: 論理的な説明、データの直接提示、カジュアルな言葉遣い

### ターゲット

女性25〜40歳。スピリチュアル好き。「当たる」より「癒される」「導かれる」感覚を重視。パワーストーンやお香に親しみがある層。

### デザイン方針

- 既存Theme A（ダークゴールド）をベースに継続
- 背景: 深い藍色、金の粒子アニメーション
- フォント: 明朝系（Shippori Mincho等）
- アクセントカラー: ゴールド（#D4A574）

### 独自機能

#### 1. 月齢連動メッセージ

- 月齢は天文計算で算出（API依存なし）
- トップページに現在の月相アイコンと1行メッセージを常時表示
- 8フェーズ対応:
  - 新月: 「種まきの夜。新しい意図を月に預けて」
  - 三日月: 「芽吹きの兆し。小さな一歩を」
  - 上弦の月: 「挑戦の月。壁があるなら、それは成長の証」
  - 十三夜: 「もうすぐ満ちる。焦らないで」
  - 満月: 「解放の夜。手放すべきものが見えるはず」
  - 十六夜: 「感謝の月。満ちたものを味わって」
  - 下弦の月: 「振り返りの時。静かに内を見つめて」
  - 二十六夜: 「浄化の月。次の新月に備えて」
- 新月・満月の日はトップに特別バナーとMadame Luneの特別メッセージ
- デイリー占いのプロンプトにも月齢情報を注入し、鑑定内容に反映

#### 2. 儀式ガイド（鑑定中ローディング）

鑑定前のフォーム送信は即座に行い、AIが生成している15〜30秒の待機時間を儀式体験に変える。

ステップ演出（5秒ずつ、計20〜30秒）:
1. 画面が暗転、月の光が中央に灯る — 「月の光があなたを包みます...」
2. 星座の線が描かれるアニメーション — 「あなたの星図を開いています...」
3. タロットカードがめくれるアニメーション — 「カードが語りかけています...」
4. 月が満ちていくアニメーション — 「Madame Luneがあなたの運命を読み解いています...」
5. 光が収束 — 「鑑定が整いました。心の準備はいいかしら？」

最後のステップでボタン「鑑定結果を受け取る」を表示。ユーザーが自分のタイミングでクリックして結果画面に遷移。

#### 3. パワーストーン処方

- 鑑定結果のセクション12として「月からの処方箋」を追加
- AIプロンプトに石の知識を組み込み、鑑定結果に基づいて3種の石を処方:
  - 石の名前（日本語 + 英語）
  - 石の意味・効能（1〜2行）
  - 使い方の提案（「左手首につけて」「枕元に置いて」等）
  - 3石の組み合わせの意味
- UIに「この石を手に入れる」ボタン枠を設置（現時点ではリンク先未定、将来EC連携用）
- 石のデータはプロンプト内で生成（外部DB不要）

#### 4. 月光カレンダー

- 月間カレンダーUI。各日セルに月齢アイコンと運勢を1行表示
- 新月・満月の日はゴールドでハイライト
- 日をタップするとその日のデイリー占い詳細に遷移
- 月齢は天文計算で算出（API依存なし）

### 鑑定出力フォーマット

既存11セクション + セクション12追加:

```
1. 魂の第一声（冒頭の一撃）
2. あなたの思考のOS（認知プロファイル）
3. あなたの「裏の顔」
4. 人間関係の磁場
5. 仕事と才能の交差点
6. お金との関係性
7. 恋愛・パートナーシップ
8. 健康とエネルギー
9. 今月の星の流れ
10. 3ヶ月予報
11. Madame Luneの最後の言葉
12. 月からの処方箋（パワーストーン3種）
```

全セクションのトーン指示: 詩的に、比喩で、物語として語る。箇条書き禁止。

## サイトB: luna-papermoon（紙の月）

### ブランドコンセプト

静かな書斎で、温かいお茶を飲みながら自分と向き合う時間。占いは「答え」ではなく「問いかけ」。

### ペルソナ: 朔（さく）

- 一人称: 「わたし」
- 語尾: 「〜だと思う」「〜かもしれないね」「〜なんだよね」
- トーン: 温かい・内省的・カジュアルだが知的
- 特徴: エッセイストのような文体。断定せず、問いかけで気づきを促す
- 語り口: 「あなたはどう感じる？」「この数字を見て、何か思い当たることはない？」「わたしはこう読んだけれど、あなたの中にある答えの方が正しいかもしれない」
- 禁止: 神秘的な演出、断定的な表現、命令口調

### ターゲット

女性20〜35歳。自己啓発・心理学好き。占いを「自分を知るツール」として使いたい。エッセイや心理テストが好きな層。

### デザイン方針

- 既存Theme B（ライト/ウォーム）をベースに継続
- 背景: オフホワイト（#FDFAF6）、紙のテクスチャ感
- フォント: 明朝系（Shippori Mincho, Kaisei Decol）
- アクセントカラー: ウォームベージュ、テラコッタ

### 独自機能

#### 1. 内省ジャーナル

- 鑑定結果の最後に「朔からの問いかけ」を1つ提示
- 問いかけ例:
  - 「あなたが最近、直感を無視した瞬間はいつ？」
  - 「"本当はこうしたい"と思っているのに言えていないことは？」
  - 「3年前の自分が今のあなたを見たら、何と言うと思う？」
- テキスト入力エリア（textarea）を設置
- 書いた内容はlocalStorageに日付をキーとして保存
- 「過去の日記を読む」ページ: 日付順に一覧表示
- AIプロンプトで問いかけを鑑定内容に基づいて動的生成

#### 2. 成長マップ

- 過去の鑑定で出た認知プロファイル（分析力/直感力/共感力/決断速度/柔軟性）を蓄積
- 時系列折れ線グラフで表示（Chart.js）
- X軸: 鑑定日、Y軸: スコア（0-100）、5項目を色分け
- グラフ下に差分ベースのテンプレートメッセージ（API不要）
- データソース: DBのReadingテーブルから認知プロファイルスコアを取得

#### 3. 行動パターン診断

- 占術結果から意思決定の癖を4象限マトリクスで表示
- 縦軸: 直感型 ↔ 分析型（直感力と分析力の比率）
- 横軸: 行動先行 ↔ 熟考先行（決断速度から算出）
- 4象限:
  - 直感×行動先行 = 「閃きの実行者」
  - 直感×熟考先行 = 「静かな予言者」
  - 分析×行動先行 = 「戦略的チャレンジャー」
  - 分析×熟考先行 = 「慎重な設計者」
- 各タイプに朔からの2〜3行の解説
- SVGまたはCanvas描画

#### 4. 朔のひとこと日記

- デイリー占いに朔の短いエッセイ風メッセージ（3〜5行）を添える
- 天気や季節に触れながら「今日という日の温度」を伝える
- デイリープロンプトに日付・曜日・季節情報を注入しAIが生成

### 鑑定出力フォーマット

セクション名をすべて問いかけ形に:

```
1. あなたは、自分をどんな人だと思っている？（魂の第一声）
2. あなたの思考の癖、気づいてた？（認知プロファイル）
3. 人に見せていない自分について（裏の顔）
4. あなたの周りの人たちとの距離感（人間関係）
5. 好きなことと得意なこと、一致してる？（仕事と才能）
6. お金に対して、本当はどう思ってる？（お金との関係）
7. 誰かを好きになるとき、あなたはどうなる？（恋愛）
8. 最近、自分の体の声を聞いてる？（健康）
9. この1ヶ月、何が起きそう？（今月の流れ）
10. 3ヶ月先の自分へ（予報）
11. 朔からの手紙（最後の言葉）
12. 今日の問いかけ（ジャーナル用）
```

各セクション末尾に朔の1行コメント。

## サイトC: VOID（ヴォイド）

### ブランドコンセプト

占いを「信じる/信じない」ではなく「検証する」もの。星と数字のアルゴリズムが出力するデータを、あなた自身が判断する。

### ペルソナ: SYSTEM

- 一人称: なし（無人称文体）
- 語尾: 「〜である」「〜と判定」「〜を出力する」
- トーン: 冷徹・分析的・端的
- 特徴: 1文が短い。箇条書きベース。占術の根拠を必ず併記
- 語り口: 「四柱推命の日柱=丙午、数秘ライフパス=7。内省型の行動パターンと判定」
- 例外: 全セクション最後の1行だけ急に人間的になる。この緩急がVOIDのブランドアイデンティティ
- 禁止: 詩的表現、感情的な言葉、曖昧な表現

### ターゲット

男女20〜35歳。占い懐疑派だが興味はある。データや統計で根拠を見たい。エンジニア・理系・論理的思考を好む層。

### デザイン方針

- 既存Theme C（ダーク/シアン）をベースに継続
- 背景: ほぼ黒（#08060E）、グリッドライン
- フォント: モノスペース（JetBrains Mono）+ ゴシック
- アクセントカラー: ネオンシアン（#00D4AA）
- UIラベルは英語ベース、コンテンツは日本語

### 独自機能

#### 1. 占術エンジン透明化（EVIDENCE）

- 鑑定結果の各セクションに「EVIDENCE」トグルボタンを設置
- トグルを開くと:
  - 寄与度: 「西洋占星術 40% / 四柱推命 35% / 数秘術 25%」（棒グラフ）
  - 入力パラメータ: 「太陽星座=蠍座, 月星座=双子座, ASC=獅子座」等
  - 判定ロジック: 1行の根拠説明
- AIプロンプトで各セクションにevidenceブロックをJSON形式で出力させる

#### 2. 精度トラッカー

- デイリー占いの的中判定データを統計ダッシュボードとして表示:
  - 全体的中率（ドーナツチャート）
  - 週別推移（折れ線グラフ、過去12週分）
  - 占術別的中率（横棒グラフ）
  - サンプルサイズ表示
- データソース: DailyFortuneテーブルのprediction_result集計
- Chart.jsで描画

#### 3. クイック診断モード

- トップページに「QUICK SCAN」ボタン
- 入力: 生年月日のみ
- 出力（30秒以内）:
  - 3行サマリー
  - 総合スコア: 0-100（プログレスバー）
  - TODAY'S ACTION: 具体的な行動指示1つ
  - RISK FLAG: 注意すべきこと1つ
- 専用の軽量プロンプト（フル鑑定の1/3トークン）
- 専用ページ `/quick`
- フル鑑定への導線: 「FULL ANALYSIS」リンク

#### 4. 比較分析モード

- 2人の生年月日を入力して相性を分析
- 認知プロファイルの差分をレーダーチャート（Chart.js radar）で重ね表示
- 工学的語彙:
  - 「補完率」: 互いの弱点をどれだけ補えるか
  - 「摩擦係数」: 衝突が起きやすい領域
  - 「共振周波数」: 価値観が一致する領域
  - 「安定度指数」: 長期的な関係の持続性予測
- EVIDENCEトグル付き

## 共通事項

### 占術エンジン

以下の占術計算ロジックは3サイトで同一だが、リポジトリは独立（各リポジトリにコピー）:

- 西洋占星術（太陽・月・ASC計算）
- 数秘術（ライフパス・ディスティニー・ソウル計算）
- 九星気学（本命星・月命星計算）
- 六星占術（星人・大殺界計算）
- 四柱推命（年柱・月柱・日柱・時柱計算）
- タロット（数秘ベースのカード対応）

現時点ではClaude APIのプロンプト内で計算。

### データベース

各サイトが独立SQLiteを保持。スキーマは共通ベースにサイト固有テーブル/カラムを自由追加可能。

### デプロイ

- GitHub上に独立リポジトリ
- RenderのAutoDeployで各リポジトリのmainブランチを監視
- 環境変数はサイトごとに独立管理
- FORCED_THEME環境変数は不要（テーマ切替機能自体を削除）
