## 学び・知見
- **`word-break: auto-phrase`はiOS Safariで未対応**: CSSプログレッシブエンハンスメントとして`keep-all`→`auto-phrase`の順で宣言し、`overflow-wrap: break-word`を併記するのが正解パターン
- **暗い紫背景(#352466)でのCJKテキスト色**: コントラスト比4.5:1以上を確保するには、紫系は#c4b5fd以上の明度、ピンク系は#f9a8d4以上の明度が必要
- **8桁hex alpha vs opacity**: `color: #c084fcaa`のようにalpha付き色指定をすると、子要素から上書きしやすい。`opacity`は子要素に乗算されるので使わない（HANDOFF.md記載通り）
- **alpha除去でコントラスト大幅改善**: テーマ色を明るくしてもalpha 80%では不十分だった。alpha除去+テーマ色ライト化の組み合わせが最も効果的
- **HEIC→JPEG変換**: macOSの`sips -s format jpeg -Z 1200`で簡単に変換可能。256KB制限のあるRead toolでも読める
- **KPカードのkpBold関数**: `：`で分割した後のlabel部分には`kpBold()`が適用されないため、`**`マーカーが残る。label側にも`replace(/\*\*/g,'')`が必要
