## 学び・知見
- **`word-break: keep-all`は日本語に不向き**: 日本語にはスペースがないため、文全体が1単語扱いになりテキストがコンテナからオーバーフローする。韓国語（スペースあり）向けの設定。日本語には`auto-phrase`（Chrome 119+のみ）かデフォルト`normal`が正解
- **暗い紫背景(#352466)でのコントラスト基準**: 紫系は#c4b5fd以上、ピンク系は#f9a8d4以上の明度が必要（コントラスト比4.5:1以上）。さらにalpha付きで使う場合はフル不透明度の色自体が十分明るくないと使えない
- **text-shadowでキラキラ感**: `text-shadow: 0 0 16px rgba(233,213,255,.18)` の微細なグロウが、デザインの質を上げるのに効果的。重すぎず軽すぎないバランス
- **HEICファイルの変換**: macOSの`sips -s format jpeg -Z 1200 input.heic --out output.jpg`で簡単にJPEG変換可能。Read toolの256KB制限を回避できる
- **pydantic_settingsの環境変数読み込み**: `BaseSettings`は環境変数名を自動でsnake_caseに変換して読み込む。`DATABASE_URL` → `database_url`
- **CSSプログレッシブエンハンスメント**: 同じプロパティを2行書くとき、後の行がフォールバックではなくオーバーライドになる。`word-break: keep-all; word-break: auto-phrase;`はauto-phraseを優先し、非対応ブラウザはkeep-allを使う
